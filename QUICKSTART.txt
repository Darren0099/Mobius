A. PULL THE UPDATE
1. Quit the older Mobius instance using its system-tray icon.
2. Open PowerShell:
   cd "$HOME\Documents\Mobius-GitHub"
   git pull --ff-only origin main
   .\run-debug-windows.bat
3. Debug mode forces the expanded window to show even over PowerShell.
   Once it works, regular launch: .\run-windows.bat
4. Keep .venv, Whisper cache and Ollama installation. No model download is
   needed again for this visual update.

B. DARK ISLAND AND CAROUSEL
- Compact island: 158×42 logical pixels; expanded: max 540px wide.
- Clicking anywhere outside the expanded panel closes it immediately.
- Switching to Chrome or another app shrinks the island before hiding.
- Point at the top-center 6-pixel edge for ~0.7 seconds to smoothly reveal it.
- Music/Focus and other panels are short; File Studio scrolls internally.
- Eyes remain the default when the desktop is active.
- Every ~38 seconds a clock/battery/music/focus glance may appear for ~10 s.
  When unplugging or plugging in charging, the battery glance gets priority.
  All glances return to the expressive robot eyes.
- When a browser or another app is foreground, the compact bar hides.
  Hover at the top-center edge (~0.7s) for temporary reveal.
  Use Ctrl+Alt+M or the tray icon to open a persistent expanded panel.
- Expand: swipe horizontally or use arrows / dots through:
  Music, Lyrics, Focus Timer, Water Reminder, File Studio, Assistant.
- Dark base colors; per-feature accents: music purple, lyrics cyan,
  focus amber, water blue, File Studio neutral, Assistant lime.
- Drag files to select the dedicated File Studio page automatically.
- Voice commands work without saying Mobius. Windows SAPI replies in English.

C. OPTIONAL MEDIA AND PACKAGING
- For native Windows media sessions once: .\install-media-windows.bat
- Generate an EXE: .\build-windows.bat, then dist\Mobius.exe.
- Or download Windows EXE/installer from successful GitHub Actions artifacts.
- Native application EXE does NOT include Whisper/Ollama model weights.

D. IF IT DOES NOT OPEN
- Run .\test-qt-windows.bat for a minimal Qt-window diagnostic.
- Run .\run-debug-windows.bat to see startup messages.
- Startup log: %USERPROFILE%\Documents\Mobius\mobius-startup.log
- Crash log: %USERPROFILE%\Documents\Mobius\mobius-error.log

See README.md for detailed behavior, privacy and limitations.

E. MONOCHROME DESIGN (v0.8.3)
- Compact eyes: 124 x 38 logical pixels (before Windows display scaling).
- Clock/battery: automatic content width, capped at 240 logical pixels.
- Expanded island: 408 logical pixels wide with internal scrollable tools.
- Bright-white text with clear contrast; restrained graphite base.
- Real custom-drawn Qt vector icons, not emoji or remote favicon fonts.
- Clean Segoe UI Variable / Segoe UI typography; subdued borders and motion.

F. RADIAL FILE STUDIO (SOURCE-ONLY REVISION)
- The top edge retains a visible line even when Chrome/VS Code is foreground.
- Drag a PDF, Word or image from Explorer onto the line.
- A separate nine-sector radial wheel appears at screen center.
- Choose a compatible sector; dimmed sectors are disabled.
- Drop directly onto a compatible sector or click the center to select files.
- Press Escape or click outside the wheel to close; robot eyes stay at top.
- New almond-shaped eyes have white eyelids and dark moving pupils.
- No installer or EXE will be generated until explicitly approved.
