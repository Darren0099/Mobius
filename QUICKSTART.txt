MOBIUS v0.7 — WINDOWS LIVING ISLAND

A. RUN FROM GITHUB (Python 3.12 installed)
1. Quit any old Mobius process from the system tray.
2. Open PowerShell and run:
   cd "$HOME\Documents\Mobius-GitHub"
   git pull --ff-only origin main
   .\install-media-windows.bat
   .\run-debug-windows.bat
3. The media-install BAT is needed only once for Spotify/Apple Music/YouTube
   controls exposed through Windows system media sessions.
4. Whisper already installed? Do not re-download. Otherwise run:
   .\install-voice-windows.bat
5. To use local Qwen language understanding, install Ollama + qwen2.5:3b
   (optional; basic commands still work without it).

B. USE THE ISLAND
- Hover the top center edge, or press Ctrl+Alt+M.
- Idle: glowing lime/emerald robot eyes; look around, blink and get sleepy.
- Playing song: island shows track name or current synchronized lyric line.
- Focus timer: island shows time remaining.
- Open island, then choose MUSIC, LYRICS, FOCUS or WATER above File Studio.
- Lyrics: Open local .LRC (offline), or explicitly Find lyrics online via LRCLIB.
- Focus: start, pause, reset; short soft chime between work and break.
- Water: adjust bottle, daily target, reminder hours and interval; log a drink.
- Voice: "buka kalkulator", "pause musik", "mulai fokus 25 menit",
         "catat minum 250 ml", "tampilkan lirik".
- Voice success confirmations are spoken in English using local Windows SAPI.
- Model weights and user water logs stay on this PC.

C. BUILD AN EXE
1. Run .\build-windows.bat on Windows, then open dist\Mobius.exe.
2. Or use GitHub Actions → Build Mobius Windows EXE → Run workflow.
   Download Mobius-Windows-EXE artifact when the build is successful.
3. Optional Mobius-Setup.exe can be generated with Mobius.iss and Inno Setup.
4. Models are not embedded. A fresh Windows user must download Whisper once.

See README.md for feature details, dependencies and limitations.
